# 🏡 GTA Housing Market Dashboard (2015–2021)

This project analyzes the Greater Toronto Area (GTA) housing market using real data from 2015 to 2021. It includes a professional-grade interactive Tableau dashboard that highlights price trends, property type comparisons, and city-level benchmarks. Users can filter by year and property type to explore insights.

---

## 📊 Tools & Technologies
- **Python (Jupyter Notebook)** – Data cleaning, feature engineering
- **Pandas** – Data manipulation
- **Tableau Public** – Dashboard development & publishing

---

## 🔍 Key Features
- ✅ Interactive filters: Year, Property Type
- ✅ KPI cards showing growth and benchmarks
- ✅ Line charts comparing price trends over time
- ✅ GTA city-level heatmap using benchmark prices
- ✅ Clean, modern UI designed for fintech/data analytics portfolio use
